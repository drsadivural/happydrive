# 製品・業務仕様 v1.0

## 1. 目的と利用者
全国の軽貨物ドライバーと地域サポーターに、配送効率化と配送以外の有償業務を提供する。利用者は①ドライバー/地域サポーター②発注企業・自治体の担当者③運営管理者④監査・サポート担当。初期リリースは日本国内、日本語、JPY/JST、iPhoneを対象。アクセシビリティのため表示倍率とVoiceOverに対応。iPadはレイアウト検証後に提供対象とする。

## 3. 業務の完全な流れ
企業登録/審査→案件下書き→募集条件・報酬・法的分類確定→公開前チェック→公開→適格者抽出→通知/検索→受諾の原子的確定→必要に応じ発注者承認→現地移動→位置の限定共有→チェックイン→手順/安全確認→証跡→完了報告→企業検収/差戻し→報酬確定→支払→双方評価。タイムアウト、無応答、キャンセル、現地不在、事故、通信断、重複受諾の復旧経路を実装する。

## 4. 配送モジュール
- 配送先の手動登録/CSV一括取込/端末内OCR。住所の候補確認と重複警告。住所の誤認識はドライバーが確定する。
- 時間窓、優先度、積込/積下ろし時間、車両制約、休憩、出発地・終点を考慮し、道路所要時間行列に基づくルート生成。厳密最適解の保証表示は禁止。制約を満たせない場合は理由と手修正を提示。
- 運行中の再計算は停車中だけ操作可能。次の目的地のナビはAppleマップ。圏外では既取得の停止順・住所・メモを暗号化キャッシュ、地図タイルの完全オフライン利用を約束しない。
- 配送状態: draft→ready→en_route→arrived→delivered / failed / deferred。失敗には理由、再配達日時、証跡を付与。完了更新は端末一時保存→接続復帰後に冪等送信。
- 写真/署名/受領時刻/位置などの証跡は案件ごとに必要項目を設定。顧客電話は必要な担当者にだけ提示し、履歴の保管期間を設定。

## 5. Happy案件
- カテゴリ: 高齢者見守り、生活支援、買い物、企業回収/調査、道路/街の情報、配送関連。医療処置・身体介護・資格が必要な業務は審査済資格と発注条件が揃うまで公開しない。「健康観察」は医療判断を含まない範囲を確認。
- 業務分類を「雇用」「業務委託」「その他（法務審査中）」として案件ごとに保持。各分類の条件・通知・支払・キャンセル規則を個別設定し、雇用を業務委託と見せかけない。公開前に発注者名称/所在地/連絡先/内容/就業場所/報酬等の表示を検証。
- 原子的な受諾: 採用枠と応募資格を同一トランザクションで検証・確保し、冪等キーで重複受諾を防止。同時最終枠は一人のみ成功。予約有効期限・待機リスト・辞退/再募集の状態を定義。
- 状態: draft→pending_review→published→reserved→accepted→traveling→checked_in→working→submitted→approved→payable→paid。分岐: rejected/cancelled/expired/no_show/disputed/needs_revision/refunded。すべての変更は理由・操作主体・時刻を追記式イベントとして記録。
- 位置: 募集時は粗い位置で候補を絞り、稼働中のみ必要な精度でチェックインを行う。依頼者に生の常時追跡履歴は表示しない。稼働終了/権限取消時は追跡停止。
- チャット: 案件内テキスト、添付、通知、運営通報、発注者との連絡。電話番号は原則非公開。高齢者宅の住所・写真へのアクセスを役割/期間で制限。
- 報酬: 見積/確定/保留/振込予定/振込済/失敗/取消の台帳と明細。架空の即時払い表現を使わない。雇用の賃金と業務委託の報酬は別会計で処理。

## 6. AIマッチング
ハード条件（資格、年齢条件が正当な場合、空き時間、エリア、業務種別、車両、稼働停止、競合予約）を先に適用。残りを移動ETA・進行方向・開始可能時刻・スキル・完了実績・公平性・本人の希望で順位付け。評価は不当な自動排除をしない。初期は決定論的スコア、各提案に「近い・時間に合う・資格適合」等の理由を表示。履歴/位置の利用同意と停止を用意。オンライン学習や需要予測は匿名化/評価データ・十分な実績が集まってから導入。運営がスコア重み/除外理由/偏りを監査できるようにする。

## 7. 非機能・運用
API 99.9%月次目標、RPO≤1時間/RTO≤4時間を設計目標。主要読取p95<500ms（外部地図/決済を除く）、受諾p95<1秒を負荷試験で測定。通信断から復帰した保留操作を重複なく同期。時刻はUTC保存/JST表示、金額は整数JPY。PUSH失敗時もアプリ内通知と検索で状態を確認可能。監査ログ、障害アラート、カスタマーサポート導線、運転中の操作抑止を必須。

## 8. 提供画像から採用した要素
白・青基調、配送ブルー/案件グリーン、HappyDriveのH/道路ロゴ、スマイル付きワードマーク、ホームの2大導線、日程/ルート/提案、業務手順、位置証跡、品質教育、収入画面。協業先ロゴ/提携表現は正式許諾なしに製品へ掲載しない。
