## 試験種類
- API: schema契約、境界値、RBAC、位置と時刻の境界、冪等性、同時実行、Webhook署名。
- iOS: ViewModel単体、ローカライズ/文字切れの画面テスト、UIテスト（オンボーディング→検索→受諾→完了→明細）、実機のGPS/省電力/圏外。
- Web: 企業の作成→公開→検収、運営の審査→紛争→逆仕訳、組織権限。
- セキュリティ: 依存脆弱性、SAST、認可IDOR、アップロード、ログPII、誤設定、バックアップ復元。
- リリースゲート: すべてのP0合格、P1例外は事業責任者が根拠を記録。テスト結果を創作しない。
