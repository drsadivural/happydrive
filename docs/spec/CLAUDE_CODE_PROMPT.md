# Claude Codeに入力する実装指示

あなたはHappyDriveの開発リードです。このリポジトリ内の `README.md`、`docs/PRODUCT.md`、`docs/ARCHITECTURE.md`、`docs/APPLE_RELEASE.md`、`docs/RESEARCH.md`、`contracts/openapi.yaml`、`database/schema.sql`、`tests/ACCEPTANCE.md`、`mockups/*.png` と `assets/` の提供画像を最初に確認してください。日本国内向けiPhoneアプリ、企業用Web、運営Web、API、DB、接続部を、実用可能な品質で完成させてください。既存リポジトリがある場合は先に構造を調べ、既存機能を維持しながら追加すること。設計資料にない外部連携が存在するかのように見せないでください。

## 作成する構成
`apps/ios` (SwiftUI/iOS 17+)、`apps/partner-web` (Next.js)、`apps/admin-web` (Next.js)、`services/api` (Node.js/TypeScript/Fastify)、`packages/contracts` (OpenAPI型生成)、`packages/design-tokens`、`infra`、`docs`、`.github/workflows`。依存のバージョンは実装開始時の互換性/セキュリティを確認してロックする。README/.gitignore/.env.example/運用Runbook/初期データ移行手順を含める。iOSコードはXcodeで開ける完全なプロジェクトとして作成する。

## 必須実装順序
1. 要件トレーサビリティ表を作り、画像の全導線と `PRODUCT.md` の画面・業務を具体的なissue/画面/API/試験に対応させる。未確定の事業判断は `docs/DECISIONS_REQUIRED.md` に記録し、合法な動作に影響する部分は本番では閉じる。ロゴの正式マスターがない間は同梱の切り出し参照を開発ビルドで使用する。
2. API/DB/認証/組織境界/イベント・outbox/冪等/アップロード/台帳を実装。スキーマ・状態遷移とOpenAPIの整合を保ち、サーバー側認可を保証する。認証SDK、決済、本人確認などは実際の契約とSandbox資格情報が揃ってから本物に接続し、モックを本番構成へ残さない。
3. ドライバーiOSの全画面を `mockups/` の情報設計に沿って作成。HappyDriveロゴ、白/青の滑らかなカード、案件の緑、日本語、ライト/ダーク、Dynamic Type、VoiceOver、エラー/空/圏外状態を実装。ユーザーの操作は3タップ程度で主要機能に到達。配送、案件、学ぶ、マイページ、通知、メッセージ、報酬を完成させる。
4. 企業画面の審査、拠点、案件の作成・編集・公開・応募管理・業務監視・検収・請求と、運営のユーザー/企業/案件審査、紛争、支払い照合、監査・分析を実装。モバイルWebでも操作可能にする。
5. サーバーの多地点最適化、MapKit/外部ナビ、位置利用の開始/終了、チェックイン、アップロード/検収、マッチング理由、報酬の一貫したフローを接続。ヘルスケアや要資格介護の案件は資格と事業審査条件が確定するまで発注不可にする。
6. `tests/ACCEPTANCE.md` のP0/P1に対応する自動試験と実機試験手順を用意し、可能な試験を実行。結果をログとビルドSHAで記録。Mac/Xcodeがない環境ではiOSビルド/実機試験を未実施と明記し、動いたと宣言しない。
7. 本番契約/証明書/Apple Developer/権利者ロゴを確認してApp Store Connectのメタデータ、Privacy Nutrition Labels、マニフェスト、権限文、正式1024pxアイコン、提出用実画面、審査アカウント、TestFlight、Archiveを準備。審査への送信は権限保有者が実施し、審査結果を確認する。

## 厳守
- `openapi.yaml` は契約の起点。実装中に不足するエンドポイント/イベントが判明したら契約を更新し、破壊的変更をレビューする。
- 電話・住所・健康情報・位置・報酬をログに出さず、公開APIが他社データを返さないよう検証する。
- 「AI推薦」は適格性のハードフィルタ、説明可能な順位、手動検索、異議申立て、公平性の測定を備える。空間位置は本人の意思と業務上の必要に従う。
- マップや決済など外部費用が変動するプロバイダには上限/タイムアウト/サーキットブレーカー/障害時の手作業を設ける。
- すべての画面ボタンが実処理に結び付くこと。スタブ/偽報酬/ハードコードされた審査結果/未接続の「完了」をリリースしない。
- 各段階で変更ファイル、設計判断、実行した試験、失敗、未実施、次のゲートを日本語で報告。完了の主張はテスト証拠によってのみ行う。
