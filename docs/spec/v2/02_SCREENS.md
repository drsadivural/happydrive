# 02 画面と日本語文言

## 情報設計
iOS下部ナビはモードにより変化。顧客: `ホーム / 依頼 / 履歴 / メッセージ / マイページ`。供給者: `案件 / 配送 / 予定 / メッセージ / マイページ`。切替はマイページのアカウント切替で、双方の資格を持つ本人だけ表示。企業管理はレスポンシブWebで `概要 / サービス / 募集案件 / 担当者 / 料金・契約 / MCP連携 / 設定`。運営Webは審査・紛争・請求/照合・監査・分析・サポート。

| ID/モック | 顧客の主操作 | 必須状態 |
|---|---|---|

## 供給者オンボーディング（モック W01にも表示）
企業/個人事業主の選択→連絡先認証→基本情報/必要書類→サービス手動入力またはMCP連携→運営審査→Stripeカード登録と7日無料の契約→公開。無料期間終了日時、以降の料金、解約方法をWebで表示。iOSは契約状況・操作を表示し、供給者向けデジタル会員料のStripe購入ボタンを置かない。

## アクセシビリティと詳細
日本語 `ja-JP`、JST日時、円表示、Dynamic Type、VoiceOver、44pt以上の操作領域、読み上げ可能なQR代替案内（運営手動確認）、ライト/ダーク、低精度/位置拒否の手動住所入力、通信エラーの再試行。企業の緑や状態色に文字ラベルを併記。本人写真や高齢者宅の写真を一覧に不用意に露出しない。
