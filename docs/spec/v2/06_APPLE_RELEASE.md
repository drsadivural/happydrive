# 06 Apple提出ゲート

## 支払区分
顧客の月額が実世界の訪問・配送等の対面サービス利用枠のみを購入するなら、Appleの「App外で利用する商品/サービス」の規則に基づきStripe等の決済手段を検討する。デジタル機能/コンテンツへのアクセスが実質的な対価ならIAP要件の再評価が必要。供給者の7日trial後の「掲載・仕事受諾のための会員機能」はデジタル機能に該当し得るため、初版はWeb申込・Stripe契約、iOSアプリ内には供給者向けStripe購入リンク/誘導を表示しない。Appleの正式審査判断を前提に、提出時点の日本向け規則/エンタイトルメントを再確認する。QRは対面業務の完了証跡でありデジタル課金を解除するコードとして使わない。

## 必須項目
App Store用正式HappyDriveアイコン1024px、権利者提供マスター、企業名/画像の許諾。利用規約/プライバシーポリシー/料金条件/解約/返金/サポートURL/アカウント削除。App Store ConnectでPrivacy Nutrition Labels、SDKのprivacy manifest/required reason APIs、収集する位置/連絡先/写真/決済識別子を実態に合わせて申告。位置When In Use、QRカメラ、通知/写真の用途文。ローカライズja-JP。レビュー用顧客と供給者（管理者/現場担当）の動作可能アカウント、カードを要求しない審査用の全機能デモ、試験案件、QR両端末手順、サーバー稼働。アカウント削除導線は両モードに実装。

## 検証
最新安定Xcode/iOS SDKに合わせてビルド。最小サポートiOS版/最新iOSの実機、少なくとも小画面/大画面、ライト/ダーク、Dynamic Type/VoiceOver、低精度/位置拒否、カメラ拒否/復帰、圏外、SMS失敗、3DS、課金失敗、二人の同時受諾、QR有効期限/再読取/取り違え、ログアウト/退会を通す。スクリーンショットは正式ビルドから撮影。TestFlight/ArchiveにビルドSHAと試験証拠を紐付け。Apple審査通過の宣言は承認結果が出てから。
