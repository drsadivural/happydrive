# API契約 変更履歴

契約の起点は `packages/contracts/openapi.yaml`。API のルーティングと入力検証はこのファイルから生成され（`services/api/src/openapi/loader.ts`）、全テストの応答は契約で検証されます（`services/api/test/contract-validator.ts`）。

## v1.1.0（2026-09-26）— 後方互換の追加のみ
v1.0（`docs/spec/openapi.v1.0-original.yaml`）の全エンドポイント・フィールドを維持し、実装に必要な項目を追加しました。

- 追加: 認証（電話OTP、リフレッシュのローテーション、Web用パスワード+TOTP MFA）、本人情報・車両・口座・規約同意・本人確認・資格提出、設定、端末登録、問い合わせ
- 追加: 配送（取得/更新/削除、CSV取込、連絡先の必要時取得、ルート取得・手動並べ替え・開始、日報）
- 追加: ホーム集約、案件のお気に入り・空き待ち、推薦への異議申立て、割当一覧/詳細、位置の限定共有、評価、チャット、通報、ブロック
- 追加: 証跡の完了検証・閲覧URL・ローカル署名URL
- 追加: 通知、報酬集計、振込履歴、講習・確認テスト
- 追加: 組織（登録・拠点・メンバー・案件の編集/申請/取消・応募/割当・予約承認・無断欠勤・現在地・請求）
- 追加: 運営（利用者/組織/案件審査、紛争裁定、逆仕訳、再割当、通報、問い合わせ、振込バッチ/再試行、照合、監査ログ/ハッシュ連鎖検証、分析、マッチング重み/監査、削除要求）
- 追加: 決済Webhook
- 拡張（互換）: `Job` に公開用フィールド、`Assignment` に状態の追加（reserved/declined/expired/no_show/refunded）、`Stop` に位置・優先度など、`NewJob` に必須の表示事項（取引条件・キャンセル規則・手順・公開用地域名・位置）。
- 変更の注意: `NewJob` の必須項目が増えています（v1.0 のクライアントは存在しないため影響なし）。`jobs.cancellation_policy` は text から構造化 JSON になりました。
- 全操作に `default` エラー応答（`Error` スキーマ）を明記。
- レビュー指摘による修正: `Site` を独立スキーマ化（allOf + additionalProperties:false で応答が常に不正になる問題）、管理系の詳細取得（`GET /admin/jobs/{id}`, `GET /admin/organizations/{id}`）、管理系変更の Idempotency-Key 必須化、列挙値の明記。

破壊的変更を行う場合は v2 のパスを追加し、iOS の最低対応バージョンを上げてから旧版を廃止してください。
