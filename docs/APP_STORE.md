## 説明文（案）
HappyDrive は、軽貨物ドライバーと地域サポーターのためのアプリです。

■ 配達アプリ
・配達先を手入力、住所検索、CSV 取込、写真からの住所読み取り（端末内で処理し、確定は本人が行います）で登録
・時間指定・優先度・休憩を考慮した配達順の提案（到着見込みは概算です）
・Apple マップでの案内、到着・配達完了・持ち戻りの記録、置き配写真と受領サイン
・電波の届かない場所でも記録を保存し、接続後に送信

■ Happy案件
・近くの買い物付き添い・見守り訪問・書類回収・地域の情報収集などの仕事を検索
・受諾前に報酬・費用負担・キャンセル条件・支払予定日・契約区分を確認
・手順に沿って作業し、写真付きで完了報告。検収後の報酬と振込予定日をマイページで確認

■ 安心して使うために
・本人確認と講習（学ぶ）、資格の確認
・位置情報は業務中のみ、必要な範囲で利用
・通報・ブロック、ヘルプ、危険の報告

※ 医療行為・身体介護を伴う業務は扱いません。報酬の即時払いはありません。

## 権限の説明文（Info.plist、実装値と一致させる）
- 位置情報（使用中のみ）: 近くの案件の表示、業務開始時のチェックイン、配達順の計算に使用します。業務中以外に位置を共有することはありません。
- カメラ: 配達・業務の証跡写真と本人確認書類の撮影、住所の読み取りに使用します。
- 通知: 案件の承認・メッセージ・報酬の確定をお知らせします。
- バックグラウンド位置情報: **使用しない**（UIBackgroundModes に location を含めない）。

## 審査メモ（テンプレート）
- 審査用アカウント: 電話番号 `REVIEW_ACCOUNT_PHONE` / 確認コード `REVIEW_ACCOUNT_CODE`（この番号のみ固定コードでログインでき、SMS は送信されません）。
- 審査用アカウントは本人確認済み・講習合格済みにし、審査期間中に受諾可能なサンプル案件（審査用の発注組織）を公開しておく。
- 試せる導線: ホーム → 案件を探す → 受諾 → 業務を進める（チェックインは案件地点から300m以内が必要なため、審査用案件は `checkInRadiusMeters` を最大 2000m に設定し、所在地を説明）→ 完了報告 → マイページ（報酬・振込予定）。配達: 配送 → 配達先を追加 → ルート → Apple マップで案内 → 配達完了。
- アカウント削除: マイページ → アカウント・設定 → 退会（アプリ内で完了）。
- 業務の報酬は物理的なサービスへの対価であり、外部の銀行振込で支払われます（アプリ内課金の対象外）。
